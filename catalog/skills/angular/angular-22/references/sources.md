# Sources

Checked on 2026-11-01 against `@angular/core@22.2.4` (npm `latest`, published 2026-10-29),
`@angular/common@22.2.4`, `@angular/forms@22.2.4`, `@angular/build@22.2.5` and `@angular/cli@22.2.5`
(published 2026-10-29), with TypeScript 6.0.3, Vitest 5.0.5 and jsdom 30.1.3 on Node 24.

Every behaviour this skill describes as measured was run in a workspace generated by
`ng new` 22.2.5 (zoneless, Vitest) with `ng test --watch=false`: zoneless refresh rules, OnPush by
default, `zone.run` being inert, NG0908, in-place mutation, `Eager` children, resource status
transitions, `ResourceValueError`, cancellation through `rxResource`/`httpResource`, `chain`,
`debounced`, compile errors NG1054/NG8118/NG5002/TS2322 and the v19 resource API failing to compile,
`fakeAsync` without zone.js, Vitest fake timers, the `whenStable` hang with an unflushed request,
`@Service()`, private members in templates, template optional chaining returning `undefined`, and
the output of the `control-flow-migration` and `signals` schematics.

## Where the docs and the package disagree or are easy to misread

- The zoneless guide says `TestBed` throws `ExpressionChangedAfterItHasBeenCheckedError` when a
  template value changes without a notification. With v22's OnPush default, assigning a component
  field and calling `fixture.detectChanges()` raises nothing and leaves the DOM stale (the component
  is simply not checked). Only `Eager` components get the error.
- The resource guide's status table says `'reloading'` shows the previous value. After an error,
  `reload()` reports `'reloading'` with `value()` `undefined` (it no longer throws).
- The angular.dev guides on `main` already describe 22.3 pre-releases in places; everything here was
  checked against the 22.2.4 package, not the docs alone.
